## Problem Statement

Meal planning takes significant time for families and individual users. Inefficient use of products already available at home leads to unnecessary expenses and food waste. Existing solutions rarely take into account three factors simultaneously: products currently available in the household, dietary preferences, and a limited family budget.

## Target Users

- Families seeking to reduce food waste and grocery expenses
- Students and young professionals with limited time and budget
- Individuals with specific dietary preferences or restrictions

## Aim

To develop an intelligent web platform that generates personalized meal plans and recipes based on available products, dietary preferences, and family budget.

## Objectives

1. Design the platform architecture, data model, and application programming interface (API).
2. Implement the server-side: user profiles, tracking of available products, dietary preferences, and family budget.
3. Develop a module for recipe generation and meal plan composition that considers available products, preferences, and budget.
4. Integrate the recipe generation module with the server-side.
5. Develop a user interface for managing products, preferences, budget, and viewing meal plans.
6. Populate the system with an initial database of recipes and products.
7. Test the main functions and evaluate the quality of the generated meal plans.
8. Prepare technical documentation and individual sections of the explanatory note.

## Expected Outcomes

- A working web platform with a responsive interface.
- A server-side that manages user profiles, available products, preferences, and budget.
- An integrated module for recipe generation and meal plan composition.
- An initial database of recipes and products.
- Architectural documentation, requirements specification, and individual sections of the explanatory note.
- Evidence of systematic development in the repository (commits, tasks, and code reviews).

## Project Scope

### In Scope
- Web application with responsive design (desktop and mobile browser)
- User profiles
- Tracking of available products
- Dietary preferences and restrictions
- Family budget tracking
- Recipe generation and personalized meal plan composition
- Initial database of recipes and products
- Testing of main scenarios

### Out of Scope
- Native mobile applications (iOS / Android)
- Automatic product recognition from photos (possible future work)
- Real-time integration with external grocery stores
- Medical or clinical recommendations

## High-Level Approach

The platform is developed as a web application. The server-side is responsible for storing and processing user data, available products, preferences, and budget. A dedicated module performs recipe selection and meal plan composition under the given constraints. The user interface enables interaction with the system. Development follows an iterative approach with regular team coordination and feedback from the supervisor.
